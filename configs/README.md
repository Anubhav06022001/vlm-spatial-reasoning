# Configuration Directory
This folder stores all hyperparameters and settings in YAML files to prevent hardcoding configuration options.

* **smolvlm.yaml**: Contains model-specific parameters, batch sizes, and learning rates for the SmolVLM model.
* **internvl.yaml**: Contains model-specific parameters, tokenization settings, and architecture scales for the InternVL model.
* **train.yaml**: Defines global training configurations including total epochs, seed numbers, and checkpoint saving paths.
