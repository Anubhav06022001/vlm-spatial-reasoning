# Vision-Language Model Wrappers
This folder provides a unified interface to load and predict using different core VLMs seamlessly.

* **smolvlm.py**: Implements the initialization and text-generation pipeline for the SmolVLM model.
* **internvl.py**: Implements the initialization and text-generation pipeline for the InternVL model.
* **paligemma.py**: Implements the initialization and text-generation pipeline for the PaliGemma model.
